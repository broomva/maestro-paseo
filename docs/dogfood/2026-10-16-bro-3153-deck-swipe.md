# Dogfood receipt: paging the phone deck (BRO-3153)

Date: 2026-10-16, ≈15:40Z. Plugin under test: `18bba00` (broomva/maestro-paseo#76), deployed live (fast-forward of `~/broomva/apps/maestro-paseo`, then `paseo plugin reload maestro`, status `running`).

**Surface.** The same hidden 402×874 `BrowserWindow` of the running Paseo app as the BRO-3146 receipt, on the live plugin and daemon. This time it was driven with **touch** events: `Emulation.setTouchEmulationEnabled` plus `Input.dispatchTouchEvent` through `webContents.debugger`. Nothing was answered; the steps were navigation only.

| Step | Deck counter |
|---|---|
| Decisions opened | 1 of 45, **Previous disabled** (`aria-disabled="true"`) |
| Tap **Next** | 2 of 45 |
| Tap **Next** | 3 of 45 |
| Tap **Previous** | 2 of 45 |
| Swipe left, diagonal (330,420 → 90,520) | 3 of 45 |
| Vertical drag with slight sideways drift (200,300 → 230,700) | 3 of 45: no accidental page |
| Swipe right (80,420 → 330,470); web allows both ways | 2 of 45 |
