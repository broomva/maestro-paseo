# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Maestro for Paseo, please report it responsibly:

1. **Do NOT** open a public issue.
2. Email `security@broomva.tech` with details, or submit a private report via [GitHub Security Advisories](https://github.com/broomva/maestro-paseo/security/advisories/new).
3. Include steps to reproduce if possible.

We will acknowledge receipt within 48 hours and aim to release a fix within 7 days for critical issues.
